# Cento — iOS-конвертер валют и криптовалют

Нативное приложение на Swift и SwiftUI. Сторонних зависимостей нет.

- **Минимальная версия:** iOS 17.0 (iPhone и iPad)
- **Сборка:** Xcode 16 или новее (проверено в Xcode 26.6), Swift 6

## Как пользоваться

- Сумму можно ввести в любой строке списка: нажмите на неё, и эта валюта станет
  валютой ввода (подсвечена синим). Остальные строки пересчитываются при вводе.
- При переходе в другую строку сравниваемая сумма сохраняется: в поле окажется
  уже пересчитанное значение.
- Пустое поле означает 1. Над клавиатурой есть кнопки «Очистить» и «Готово».
- Под каждой суммой показан курс за единицу, например «1 EUR = 1,1186 USD».
- «+» добавляет валюту. Переключатель вверху окна: «Фиат» или «Крипта».

## Запуск

1. Откройте `CurrencyRates.xcodeproj` в Xcode.
2. Выберите схему **CurrencyRates** и симулятор iPhone.
3. Нажмите ⌘R.

Для запуска на устройстве: Target → Signing & Capabilities → выберите свою команду (Team).

## Источники курсов (без API-ключей)

| Тип | Источник | Обновление |
|-----|----------|------------|
| Фиат | [ExchangeRate-API](https://www.exchangerate-api.com), `open.er-api.com/v6/latest/USD` | раз в сутки |
| Крипта | [CoinGecko](https://www.coingecko.com), `api.coingecko.com/api/v3/simple/price` | несколько раз в минуту |

Оба источника отдают курсы к USD. Пересчёт между любыми двумя валютами выполняется
на устройстве. Источники указаны в настройках, как того требуют их условия; на главном экране они появляются, когда показываются сохранённые курсы.

У публичного API CoinGecko есть ограничение на частоту запросов. При превышении
приложение показывает понятную ошибку и оставляет последние цены. Если нужен ключ
CoinGecko или платный тариф ExchangeRate-API, не прописывайте ключ в коде.
Создайте файл `Secrets.xcconfig` и добавьте его в `.gitignore`. Пробросьте значение
в Info.plist и читайте его через `Bundle.main.object(forInfoDictionaryKey:)` в `RatesService`.

## Структура

```
CurrencyRates/
├── App/CurrencyRatesApp.swift      — точка входа, тема окна, автообновление
├── Models/Models.swift             — Currency, CryptoAsset, RateSet, RatesSnapshot, форматирование
├── Services/RatesService.swift     — запросы к API через URLSession + async/await
├── Store/RatesStore.swift          — состояние, сумма, сохранение и кэш курсов
├── Views/
│   ├── CurrencyListView.swift      — главный экран: список с вводом суммы в любой строке
│   ├── CurrencyRow.swift           — строки списков
│   ├── AddCurrencyView.swift       — добавление валюты (Фиат / Крипта, поиск)
│   └── SettingsView.swift          — тема и сведения об источниках
└── Preview Content/PreviewData.swift — демо-данные только для SwiftUI Preview
```

## Хранение данных

- Список валют и его порядок, исходная валюта, сумма и тема хранятся в `UserDefaults`.
- Последние курсы сохраняются в `Application Support/rates-cache-v2.json`. Если
  источник недоступен, показываются сохранённые курсы с пометкой и временем загрузки.
  Фиат и крипта помечаются отдельно.
- При ошибке курсы остаются на экране. Под списком появляются описание ошибки
  и кнопка «Повторить загрузку».
- Демо-данные для Preview помечены `isDemo`, и интерфейс подписывает их как
  «Демонстрационные данные, не реальные курсы».
