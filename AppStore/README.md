# App Store screenshots

Exported from Figma (page "valyuta", frame with 64 artboards). One folder per app language, then device:

```
AppStore/<Language>/iPhone/  01-Main · 02-Many-currencies · 03-Crypto · 04-Custom-icons   (1320 × 2868, 6.9")
AppStore/<Language>/iPad/    01-Main · 02-Many-currencies · 03-Crypto · 04-Custom-icons   (2064 × 2752, 13")
```

Languages: English, Русский, Türkçe, Français, Español, Deutsch, 中文, العربية.

Notes:
- PNG, RGB without alpha (App Store Connect rejects transparency).
- App UI inside the iPad screens is in English for all languages (headlines are translated).
- iPad 04-Custom-icons is a layout built in Figma, not a device capture.
